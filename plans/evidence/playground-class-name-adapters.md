# Playground native compiler previews

The selected engine owns both the DOM classes and the emitted stylesheet.
There is one source evaluation, followed by the owning compiler/runtime.
The preview document receives the actual CSS with native resets, layers,
conditions and variables intact. No second atomic evaluation, forced
sheet-backed external strategy, token substitution in emitted CSS, or inferred
inline declarations simulate an external engine.

| Engine               | Executed implementation                                              | Configuration                                                                                |
| -------------------- | -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Atomic / named atoms | YumCSS runtime sheets                                                | Authored preset                                                                              |
| Panda                | Generated `css()` + official Generator 1.12.1 atomic encoder/decoder | Official resolved base/Panda presets, extended with example property bindings and conditions |
| Tailwind             | Public `tailwindcss.compile` 4.3.3                                   | Installed Tailwind package CSS + generated example theme                                     |
| UnoCSS               | `createGenerator` + `preset-wind3` 66.10.0                           | Explicit wind3 preset; verified scalar example bindings resolved before compilation          |
| StyleX               | Babel browser plugin + `stylex.props` 0.19.1                         | Native style objects with resolved scalar example values and supported native conditions     |

Panda artifacts come from the official config loader and generator. Imported
preset function references preserve closures; unavailable function ownership
fails generation. `panda:metadata:check` guards the checked-in artifacts.
Panda's stock `backgroundColor` class prefix is `bg-c`, with `_` as the default
separator. Independent generated-runtime parity tests cover stock/custom utility
metadata, disabled presets, conditions, prefixes, whitespace and important values.
The library's lightweight StyleX-shaped strategy stays sheet-backed; the
playground uses the native compiler instead and documents that distinction.

`PreviewExecution` cancels replaced work and prevents stale completion publication.
Pending work removes the old preview. Compiler errors display instead of retaining
successful CSS. Actual YumCSS companion rules from `css.vars()` or a strategy
fallback remain alongside the native stylesheet; they are generated by the real
runtime, not a forced sheet-backed substitute. Unsupported dynamic bindings or native selector semantics fail
explicitly. The sandbox's existing host-rendering limits still apply; this is not
a whole arbitrary-project build environment.

These are emitted chunk sizes, not a claim about total route transfer: shared
chunks are additional. The user explicitly authorized larger playground bundles
for actual compilers. They load through the engine registry; default YumCSS
runtime budgets and snapshots remain unchanged. The standalone Panda adapter's
48-byte gzip increase buys correct native value normalization.

Validation includes 65 evaluator/engine unit tests, 12 Panda parity/runtime-size
tests, production build and 37 static Chromium checks for all six engines, CSS/DSS
parity, adapter switching, prop changes, native hover conditions, no inline
specimen overrides, and stylesheet disablement removing the styling. An
unsupported StyleX selector removes the frame and displays the compiler boundary
error. Existing editor scenarios, inspector panels, theme-aware component tokens
and preview controls are checked against the built static application.

The old theme browser expectation was corrected: the authored component maps
its dark empty state to semantic.bg.primary (blue), not semantic.bg.muted (gray).
No declaration override is used to satisfy a stale expectation.

Comments about fake declaration resolution and second evaluation were discarded
with those paths. Native configuration ownership, closure preservation,
cancellation and document-isolation invariants remain in their owner modules.
